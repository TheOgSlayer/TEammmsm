# JalebiTeams

Teams plugin for JALEBI SMP (Paper 1.21.7+).

- `/teams` (aliases `/team`, `/jteam`) opens the team dialog
- No team: Create Team / Join Team
- In a team: Home, Leave (members) or Kick Players + Disband (captain)
- Teammates cannot damage each other

## Build
Push to GitHub, open the **Actions** tab, download the `JalebiTeams` artifact (the jar).
Or locally: `mvn package` (Java 21).
